# Motor Mount — Two-Shop Audit Findings

**Part:** Motor Mount (Aviocian Technologies, Al 6061, SX_2627_007)
**Shop 1:** TS — Sinumerik 828D, 4 setups, NX CAM (MPF files)
**Shop 2:** Krishna Engineering — PowerMILL/Fanuc, 3 settings (TAP files)
**Date:** 2026-06-23

---

## Key Differences

### 1. Setup Count: TS=4 vs Krishna=3

TS has a dedicated **Setup 3 (Finish)** that re-machines step floors from Setup 1 after the part
has been flipped for Setup 2. This corrects floor flatness disturbed by the flip.

Krishna skips this — they tolerate the floor finish from the first setting. Inspection shows both
shops pass all critical dimensions except the 5mm shoulder (SL 13).

**Implication for pipeline:** The extra finish setup is a quality upgrade, not a physics
requirement. Model it as optional, triggered when floor flatness tolerance is tight (<0.05mm).

### 2. Roughing Strategy: HSM (TS) vs Conventional (Krishna)

TS runs trochoidal/dynamic roughing at S=4461, F=10000 mm/min. Krishna runs conventional passes at
S=3000, F=1000 mm/min — a 10x feed rate difference for the same feature.

Both produce acceptable parts. This is entirely a CAM software + machine capability decision:
- TS: NX CAM + Sinumerik 828D with high-speed spindle
- Krishna: PowerMILL with standard Fanuc VMC

The pipeline computes conventional feeds correctly. HSM toolpath strategy is generated by CAM
software, not process planning — the right split is maintained.

### 3. Drilling: Explicit (TS) vs Absent from Files (Krishna)

TS has explicit drill cycles: 2mm center drill -> 2.5mm twist drill -> 3.2mm -> 3mm drill.
Krishna TAP files contain zero drill operations, yet Krishna inspection shows drilled holes
passing (phi3.2, phi2.5 tapped holes present in report).

Two likely explanations: (a) Krishna drills on a separate drill press, not the VMC, or (b) drill
programs were not shared in the file set.

**Implication for pipeline:** The spot_drill -> twist_drill sequence remains valid. Pipeline should
note in setup output that drilling may be on a separate machine.

### 4. Chamfer: Dedicated Mill (TS) vs Not Captured (Krishna)

TS uses a dedicated 10mm x 45deg chamfer mill (T10) in two passes per setup. No chamfer TAP file
exists for Krishna. Krishna parts passed visual inspection — they likely chamfer with an EM edge
or hand deburring.

### 5. Ball Nose for Radius Finishing — Both Shops

Both independently use ball nose for step-bottom and fillet radius finishing:
- TS: 5mm ball nose + 8mm bull nose R1
- Krishna: 4mm ball nose (1st setting), 3mm ball nose (2nd setting)

Physics-driven: only a ball/bull nose can trace a concave radius correctly.
The pipeline has no fillet-finish step currently. This is a gap.

### 6. Bore phi16.1 — Both Use 10mm EM Circular Interpolation

Both shops independently use 10mm EM circular interpolation for the 16.1mm bore.
The pipeline currently routes holes >32mm to circular interp. This finding extends that strategy
down to ~14mm and confirms 10mm EM for this diameter range.

### 7. Consistently Difficult Dimension: SL 13 (5mm shoulder)

The 5mm shoulder dimension (tol +/-0.1mm) was failed by TS (all 9 parts marked Not OK) and
borderline/unmeasured by Krishna ("-" remark for all 5 parts). Both shops struggled with the
same feature independently.

This strongly suggests a feature where tool deflection or setup error dominates, not a process
planning error. Should be flagged in inspection planning output.

## Recommended Pipeline Updates

1. **tool_selection.py:** For holes 14-32mm, prefer 10mm EM circular interp. Update threshold:
   boring_bar only for >32mm; circular_interp for 14-32mm.

2. **process_selection.py:** Add ball_nose_finish operation for any feature with fillet_radius > 0.
   Select tool_dia = fillet_radius x 2 (next standard size down if unavailable).

3. **setup_planning.py:** Add bore_last_setup flag for parts with primary bore. Add note:
   "Drilling may be on separate drill press — confirm with shop."

4. **9. program_sheet.py:** Flag small shoulders <=5mm at tol +/-0.1 as
   "DIFFICULT — verify tool deflection" in program sheet warnings.

5. **parameter_calculation.py:** Verify finish feed for 10mm EM floor pass is <=500 mm/min for
   aluminium. Both shops use 300-500 mm/min for floor passes (vs 800-1000 for walls).
