=== TOOL_NAME FIELD (DATA QUALITY NOTE) ===
The tool_name field does NOT contain tool names.
It stores multi-line G-code program text - the currently executing program blocks.
Examples:
  "CYCLE210(0)\nCYCLE206("7",1,0,0)\nM32\n"
  "N138 G90 G40 G64 G94 G54\nN139 T8\nN140 M06..."
  "G90G54\nT1D1;(C-D)[M10]\nM16\nM03S1200\n..."
The analytics.controller.js parseGCode() function extracts tool data from these blocks.
